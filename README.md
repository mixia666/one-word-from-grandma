One word is all Grandma has to say about AI: **unplugit**. Fifty years of household machines have taught her that whatever the new gadget is doing, the fix is the same — unplug it, count to ten, plug it back in. This program writes that one word, exactly as she would text it (no spaces, she never bothers), to `/output/entry.txt` for the judges.

## Run it

```sh
node main.ts
```
